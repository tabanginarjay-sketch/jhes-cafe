# 📁 Airtable CSV Import Templates

Nandito lahat ng handang CSV templates para sa **Jhe's Cofe'**.

## 🚀 1-Click Import Steps:
1. Buksan ang iyong Base sa [airtable.com](https://airtable.com).
2. I-click ang **`+ Add or import`** sa tabi ng table tabs ➔ piliin ang **`CSV file`**.
3. Piliin o i-drag and drop ang mga sumusunod:

| File Name | Pangalan ng Table sa Airtable |
|---|---|
| `1-Products.csv` | **`Products`** |
| `2-Categories.csv` | **`Categories`** |
| `3-Inventory.csv` | **`Inventory`** |
| `4-Staff.csv` | **`Staff`** |
| `5-Orders.csv` | **`Orders`** |
| `6-OrderItems.csv` | **`OrderItems`** |
| `7-Users.csv` | **`Users`** |
| `8-Payments.csv` | **`Payments`** |

Para sa kumpletong paliwanag kung paano kukunin ang Base ID at Token, tingnan ang:
